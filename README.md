# craft_aris

`craft_aris` — единый автономный coding-агент для создания и изменения веб-приложений,
мобильных интерфейсов и небольших программных проектов.

Агент работает в одном рабочем каталоге, планирует задачу, читает и изменяет файлы,
запускает команды и повторяет проверку до завершения работы.

## Возможности

- планирование и пошаговое выполнение задачи;
- чтение и поиск файлов проекта;
- создание и изменение файлов;
- запуск сборочных и тестовых команд;
- автономное исправление ошибок;
- поддержка любого OpenAI-compatible API;
- защита от выхода за пределы рабочей папки;
- тайм-аут и лимит итераций.

## Требования

- Python 3.10+;
- доступ к OpenAI-compatible API;
- переменная `CRAFT_ARIS_API_KEY`.

## Установка

```bash
cd craft_aris
python -m pip install -r requirements.txt
```

## Настройка

Скопируйте `.env.example` в `.env` и заполните параметры:

```dotenv
CRAFT_ARIS_API_KEY=your-api-key
CRAFT_ARIS_BASE_URL=https://api.openai.com/v1
CRAFT_ARIS_MODEL=gpt-4.1-mini
```

Либо задайте переменные в терминале.

## Запуск

```bash
python craft_aris.py --workspace ./мой-проект --task "Создай адаптивный лендинг на HTML и CSS"
```

Интерактивный режим:

```bash
python craft_aris.py --workspace ./мой-проект
```

Проверка конфигурации и доступности API:

```bash
python craft_aris.py --check
```

Запуск тестов проекта агента:

```bash
python -m unittest -v test_craft_aris.py
```

## Безопасность

Агент ограничивает чтение, запись и выполнение рабочим каталогом. Команды с опасными
операциями, включая удаление корня или системных каталогов, запрещены. Рекомендуется
запускать агент только в отдельной рабочей папке или репозитории.
